# SmartDash - мотоцикловый цифровой прибор на ESP32

## Описание проекта

SmartDash - это компактный дополнительный прибор для мотоцикла, построенный на базе платы ESP32-2424S012 с 1.28-дюймовым круглым IPS ЖК-экраном 240x240. Устройство подключается по Bluetooth к ELM327-совместимому адаптеру, считывает данные с бортовой диагностики мотоцикла и отображает их в минималистичном круглом интерфейсе, оптимизированном для удобства восприятия в движении.

## Целевая платформа

- **Микроконтроллер:** ESP32 (на плате ESP32-2424S012)
- **Дисплей:** 1.28" круглый IPS LCD, разрешение 240x240 пикселей (SPI интерфейс)
- **Тач-контроллер:** На основе сенсорного экрана платы (уточнится при получении платы/распиновки)
- **Связь с мотоциклом:** ELM327 адаптер (Bluetooth Classic и BLE) - подключается к диагностическому разъёму мотоцикла через переходник
- **Питание:** Через кабель Type-C
- **Управление:** Только сенсорный экран

## Тестовый мотоцикл

- **Модель:** Honda Dunk AF78
- **Диагностический разъём:** Специфичный мото-разъём Honda 4-pin, используется переходник Honda 4 pin -> OBD2 для подключения ELM327
- **Красная зона RPM:** с 8000 об/мин

## Принятые решения

- **Среда разработки:** Arduino IDE
- **Автоподключение:** При включении устройство сразу пытается подключиться к последнему сохранённому ELM327 адаптеру
- **Интерфейс:** Минимальный - только скорость по центру, шкала RPM по периметру, температура двигателя и напряжение внизу
- **Настройка:** Без веб-интерфейса, минимальная конфигурация через автоконфиг/сенсорное меню при необходимости
- **Кнопки:** На плате есть кнопки on/off, boot, reset, основное управление планируется через тачскрин

## Основные функции

| Параметр | Отображение | Приоритет | Примечание |
|---|---|---|---|
| **Скорость** | Крупные цифры по центру экрана | Критический | Основной показатель. Единицы измерения - км/ч (настраиваемо) |
| **Обороты двигателя (RPM)** | Шкала по периметру круга | Критический | Визуальная индикация в виде дуги/сегментов, заполняющей окружность. Цветовая индикация при приближении к красной зоне (настраиваемо по модели мотоцикла) |
| **Температура двигателя** | Мелкие цифры внизу экрана | Важный | Охлаждающая жидкость (Engine Coolant Temp) или температура масла - в зависимости от доступных PID мотоцикла. Единицы - °C |
| **Напряжение бортсети** | Мелкие цифры внизу экрана (рядом с температурой) | Важный | Напряжение аккумулятора/бортсети. Помогает отслеживать работу генератора. Единицы - В |

## Дизайн интерфейса

Экран круглой формы 240x240 требует особого подхода к компоновке:

```
        ┌─────────────────┐
      ╱   [RPM ШКАЛА]    ╲
     │                   │
     │    000 км/ч       │  <- Крупный шрифт, по центру
     │                   │
      ╲                 ╱
        └─[T:XX°C][U:XX.XV]┘  <- Мелкий шрифт, внизу по дуге/линейно
```

- **Центр:** Скорость - максимальный размер шрифта, хорошо читаемая при быстром взгляде
- **Периметр:** Шкала оборотов - тонкая дуга, заполняющаяся по часовой стрелке от 0 до максимальных оборотов. Рекомендуется использовать цветовую градацию (синий/зелёный -> жёлтый -> красный)
- **Нижняя часть:** В две колонки/на одной линии мелким моноширинным шрифтом выводятся температура двигателя и напряжение бортсети
- **Фон:** Тёмный (#000000) для минимального отвлекающего эффекта и лучшей читаемости на солнце
- **Анимация:** Минимальная, только плавное заполнение шкалы RPM при изменении

## Требования к функционалу

### Подключение и связь
- [ ] Автоматический поиск и подключение к ELM327 по Bluetooth (Classic) при старте
- [ ] Автоподключение при наличии сохранённого устройства

- [ ] Поддержка BLE ELM327 (опционально, но желательно с учётом ESP32-C3)
- [ ] Настройка через простой веб-интерфейс по Wi-Fi (AP-режим при первом включении) или конфигурационный файл

### Чтение данных (OBD-II PIDs)
| PID | Назначение | Приоритет |
|---|---|---|
| `010D` | Vehicle Speed (км/ч/миль/ч) | Обязательный |
| `010C` | Engine RPM (об/мин) | Обязательный |
| `0105` | Engine Coolant Temperature (°C) | Желаемый |
| `010F` | Intake Air Temperature (°C) - fallback если нет температуры двигателя | Альтернативный |
| `ATRV` / чтение через ELM | Battery Voltage (напряжение бортсети) | Обязательный (ELM может отдавать `ATRV` без OBD PID) |

> Примечание: не все мотоциклы поддерживают полный набор PID. Необходимо реализовать fallback-логику и отображать `--` при недоступности данных.

### Интерфейс и UX
- [ ] Экран блокировки/статус подключения при отсутствии данных
- [ ] Настройка максимальных оборотов для корректного отображения шкалы RPM
- [ ] Настройка красной зоны оборотов
- [ ] Переключение единиц (км/ч/миль/ч, °C/°F)
- [ ] Автоподключение по питанию (от прикуривателя/ACC мотоцикла)
- [ ] Низкое энергопотребление - отключение/затемнение не требуется, работает постоянно при включённом зажигании

### Надёжность
- [ ] Фильтрация выбросов (защита от кратковременных неверных значений)
- [ ] Таймаут обновления данных - при отсутствии новых данных дольше N секунд отображать индикацию потери связи
- [ ] Корректная работа при медленном ответе ELM327
- [ ] Сброс при переподключении

| ELM327 адаптер | OBDLink MX+, vLinker FS, или любой совместимый с ELM327 v1.4/v1.5 (Bluetooth) | Важно проверить совместимость именно с мотоциклом |
| Корпус | 3D-печатный под руль/кронштейн | Компактный, защищённый от влаги по возможности |
| Питание | От бортсети мотоцикла 12В через DC-DC down-конвертер (например, MP1584) на 5В/3.3В | Либо напрямую через стабилизатор с учётом падения напряжения |

### Примерный пин-аут (SPI дисплей GC9A01)
| ESP32-C3 | GC9A01 | Назначение |
|---|---|---|
| GPIO2 (пример) | SCK | SPI Clock |
| GPIO3 (пример) | MOSI/SDA | SPI Data |
| GPIO10 (пример) | CS | Chip Select |
| GPIO6 (пример) | DC/RS | Data/Command |
| GPIO7 (пример) | RST | Reset |
| 3.3V | VCC | Питание |
| GND | GND | Земля |

> Точные пины могут отличаться в зависимости от разводки платы. Рекомендуется вынести в `config.h` с возможностью переопределения.

## Рекомендации по реализации

- **Парсинг ELM:** ответы ELM могут приходить с пробелами, переводы строк `\r\n>`. Нужно надёжно парсить hex-ответы
- **Частота опроса:** для скорости и RPM достаточно 100-250мс. Более частый опрос не всегда поддерживается ELM/mотоциклом
- **Производительность:** использовать двойную буферизацию при отрисовке или минимизировать перерисовку статичных элементов (шкала, разметка) - перерисовывать только меняющиеся значения
- **Круглый экран:** при расчёте позиций элементов учитывать центр (120,120) и радиус. Для текста по кругу или простого позиционирования по углам - подбирать эмпирически
- **Совместимость:** начинать с `ATSP0` (автовыбор протокола) для максимальной совместимости
- **Безопасность:** устройство только для отображения информации, не должно вмешиваться в работу ЭБУ мотоцикла

## Известные ограничения

- Не все мотоциклы отдают одинаковый набор PID через OBD-II
- Некоторые мотоциклы используют нестандартные протоколы/разъёмы (K-Line, не ISO 15765)
- ELM327 дешёвых клонов может иметь задержки/ошибки
- Круглый дисплей требует больше внимания при вёрстке UI чем прямоугольный
- На некоторых мотоциклах напряжение бортсети лучше брать через `ATRV`, а не через OBD PID
